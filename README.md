# 📚 Parcial 2/3 - Estructuras de Datos

Repositorio para la resolución del parcial de Estructuras de Datos. 
Este trabajo contiene implementaciones propias de estructuras de datos lineales y jerárquicas desde cero, sin utilizar las colecciones nativas de Java.

## 🛠️ Estructuras Implementadas
En el paquete `estructuras` se desarrollaron las siguientes clases basándose en el manejo de nodos y referencias:
* **Estructuras Lineales:**
  * Pila (Stack) - Política LIFO
  * Cola (Queue) - Política FIFO
  * Listas Enlazadas Simples
* **Estructuras Jerárquicas (No Lineales):**
  * Árbol Binario de Búsqueda (ABB)
  * Lógica base para Árboles AVL (Balanceo y Factor de Equilibrio)
